# Attic

Material kept for the record rather than for use.

Nothing here is reference documentation. It is the history of how the dashboard
came to be the way it is — useful when you want to know *why* a decision was
made, or what a change cost, and misleading if read as a description of how
things work today. For that, see [`../dashboard/`](../dashboard/).

| | |
|---|---|
| [`project-log.md`](project-log.md) | Chronological record of the v2 work: what changed, what it broke, what that cost. Newest first. |
| [`plan/`](plan/) | The plans the v2 work was executed against, with their per-item status as of completion. Superseded by the documentation they produced. |

Two things worth knowing before reading the plans:

- **Each opens with a "Starting point" section describing v1.1.0.** Those sections
  are deliberately frozen — they record what the work was responding to, not
  what exists now.
- **Their reasoning was sometimes wrong, and the log says where.** The hosting
  decision, the version number, and the "stable identifiers" item all changed
  once the work met reality. Where a plan and the log disagree, the log is later.
